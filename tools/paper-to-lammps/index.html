How to use the result

        
    
          
  • Check every value with the Source button — the tool reads the paper with rules, not with understanding, so it can pick the wrong number.
    • 
          
  • Values from other papers (in the Introduction) are down-weighted, but can still appear as alternatives in the drop-down.
    • 
          
  • The script is a starting point: download the potential file, build the structure if the script says so, and fix every [TODO] line.
    • 
          
  • Graphene / h-BN sheets and fcc, bcc, hcp, diamond and zinc-blende crystals are built directly in LAMMPS. Nanotubes, MoS₂, polymers and water need a data file from another tool — the script tells you which one.
    • 
          
  • Want a second opinion? Copy AI prompt gives you a ready-made prompt with the paper's Methods text for ChatGPT, Claude or Gemini.
