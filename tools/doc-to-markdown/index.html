Tips for best results

        
    
          
  • Word files give the cleanest output — headings, lists, tables and images are read exactly as written.
    • 
          
  • PDFs are rebuilt from their layout. Headings, paragraphs, lists, simple tables and two-column papers are detected automatically. Always give the result a quick check.
    • 
          
  • Scanned PDFs (photos of pages) have no real text, so only the page images can be saved.
    • 
          
  • Old .doc files aren't supported — open them in Word and use File → Save As → .docx.
    • 
          
  • Charts drawn as vector graphics are saved when they have a “Figure N” caption. Turn on “Also save every page as an image” to catch anything else.
